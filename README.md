# mohamed-elsayed-etman
Welcome to the official digital hub of Mohamed Elsayed Etman, visionary tech entrepreneur, Founder, and CEO of Progzt Aetheric — pioneering software, AI, and digital systems

## Base design shell

- `template.html` is the bilingual Arabic/English starter shell; its page content and navigation destinations are intentionally blank.
- `css/style.css` contains the shared monochrome layout and responsive shell styles.
- `js/core/ui.js` handles the language toggle, persisted language preference, and back-to-top control.
- `assets/` is reserved for shared visual assets.
